# Assignment 2

This repository contains practice projects and assignments developed across multiple weeks while learning JavaScript, Node.js, Express.js, and MongoDB. The project is organized into folders based on weekly topics and backend applications.

## Project Structure

* week-1: JavaScript fundamentals and concepts
* week-2: Advanced JavaScript concepts and Todo application
* week-3: Basic Express backend APIs
* BackendMongoDB: Express backend connected with MongoDB
* Ecommerce: E-commerce backend with user and product APIs

---

## Ecommerce README

# Ecommerce Backend Application

This project is a backend application for an e-commerce system using Express and MongoDB.

Features:

* User management APIs
* Product management APIs
* Database connectivity
* Password encryption support
* Cookie parsing support

Technologies:

* Node.js
* Express.js
* MongoDB

* cookie-parser

npm install
